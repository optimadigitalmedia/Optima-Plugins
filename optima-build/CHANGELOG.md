# Changelog

## 0.7.4.5 (2026-10-28)

- Includes Optima layer revision 3 (0.7.4.3 below) and two fixes first delivered by hand as 0.7.4.4:
- Site health, Search engines: a staging copy behind the host's password protection, or one the theme already marks noindex, now reads "Kept out on staging" instead of asking for a password that is already on. The check could not see host passwords before, so it warned on every staging site forever.
- Features screen: the step number on recommended cards used the class of the Site health checklist, so every card also showed a stray "01" counter. It has its own class now.

## 0.7.4.3 (2026-10-28)

- Optima release of upstream 0.7.4.
- Optima layer revision 3: the Optima admin screens use IBM Plex Sans for body text (Optima design system v2, October 2026), replacing Nunito Sans.

## 0.7.4.2 (2026-10-27)

- Optima release of upstream 0.7.4.
- Optima layer revision 2: the section nav styled on plain WordPress screens (the kit stylesheet gets its own handle, so the theme's admin stylesheet no longer replaces it), and icon chips on feature cards.
