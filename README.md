# Optima Plugins

The plugin suite behind every Optima client website: business identity, content
model, schema and SEO, AI search, forms protection, reviews, team credentials,
case results, hours, redirects, accessibility and more.

**The one rule:** functionality in plugins, presentation in the theme. Switching
a theme never orphans content.

## Install

1. Upload and activate `optima-build` (the hub). It installs and updates the rest.
2. Open **Optima → Features**, set the site's plan, turn on what the site needs.
3. Fill the business details once in **Optima → Business info**. Every plugin
   reads them from there.

Plugins update themselves from this repo's releases. See `RELEASING.md`.
